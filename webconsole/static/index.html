PiDP-11 — Manual

  1. Open the portal tile PiDP-11 (or this page).
  2. Pick an OS: dropdown at the top — 2.11BSD, RT-11, RSX-11M-Plus, RSTS/E V7, DOS-11, UNIX v1/v5/v6/v7, System III, System V, 2.11BSD+, and demos (Blinky, Idle). Click BOOT. The simulator restarts with the chosen OS; the physical panel just goes along.
  3. Console tab: boot messages show up here, and this is where you work in every OS. Note: shared with the physical panel — whatever you type here applies there too.
  4. DZ Terminal tab: a real login terminal, only for OSes marked "• DZ" (2.11BSD, 2.11BSD+, RSX-11M-Plus, RSX-11M+ BQ). Opening the tab connects; press Enter for the login prompt.
  5. Boot times: RT-11 and the small UNIXes boot in seconds; 2.11BSD(+) needs 1–2 minutes (fsck + multiuser) before the DZ line gives you a login prompt.

Note

  • After booting via the web interface, "XDG_RUNTIME_DIR is invalid" shows up once on the console — cosmetic, the panel and simulator work normally.
  • Switching OS is a hard reset for the running OS, same as the physical switches. 2.11BSD recovers via fsck; shutting down cleanly from the console (shutdown/halt) is friendlier if something important is running.
  • The boot/run switches on the physical panel are ignored while a session was started via the web interface.
